# Python for Office - Offline installable
(no firewall warning)

Python environment for office automation and office tasks.

Includes Python 3.x and all required packages to run office automation scripts.
Installable without internet connection.


**How to install?**

Just unzip the folder, then right click - Run as administrator - on  **setup.bat**

HUN:

Internetelérés nélkül telepíthető (tűzfalmentes) python csomag irodai bővítményekkel, automatizáláshoz.

**Telepítés:**

-csomagold ki a tömörített mappát 
-jobb klikk a **setup.bat** fájlon
-futtatás rendszergazdaként
