# Python for Office - Offline installable
(no firewall warning)

Python environment for office automation and office tasks.

Includes Python 3.x and all required packages to run office automation scripts.
Installable without internet connection.


**How to install?**

-double click on the exe file and the installation will be done automatically

**Telepítés:**

-dupla klikk az exe fájlra és automatikusan lefut a telepítés
